# PhonePe Digital Payments Analysis

## Project Overview
This project analyzes PhonePe digital payment data to explore transaction trends, geographical patterns, user activity, and demographic relationships using Python and data analysis libraries.

## Project Structure
- `data/` — Raw dataset
- `notebooks/` — Jupyter Notebook containing the analysis
- `outputs/` — Generated outputs, including the district name-to-code mapping
- `docs/` — Business questions for the case study

## Dataset
- `data/phonepe-pulse_raw-data.xlsx`

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis
The notebook covers data loading and understanding, exploratory data analysis, data quality checks, data merging, visualization, and findings.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `notebooks/Phonepe_CaseStudy.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
